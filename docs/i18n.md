# Languages

The app ships in English, German, French, Italian and Spanish, following the device
language with an override in settings. English in `src/i18n/locales/en.json` is the source
catalogue; the other four are translated from it.

## Adding copy

1. Add the key to `en.json`, grouped by the screen or feature that uses it.
2. Add the same key to `de.json`, `fr.json`, `it.json` and `es.json`.
3. Use it with `useTranslation` in a component, or `i18n.t` outside React.

Keys are type-checked against the English catalogue, so a missing or misspelled one is a
compile error rather than a screen rendering `alerts.title` to a user.

Validation messages are copy too. Schemas that carry messages are built inside the
component from the translator, rather than at module scope, so they follow the active
language.

## What the tests enforce

- Every locale has exactly the keys English has, no more and no fewer.
- No value is empty.
- No translation drops an interpolated value. A German string that loses its placeholder
  would otherwise render a sentence with a hole in it.

## Plurals

i18next plural suffixes, which means `_one` and `_other` keys rather than a count baked
into the string.

```json
"occurrences_one": "{{count}} occurrence",
"occurrences_other": "{{count}} occurrences"
```

## Numbers, dates and units

Formatted through `Intl` with the active locale, so a German reader sees a comma in every
kilowatt figure and a French reader gets relative times in French. Unit conversion happens
only in `src/lib/format-energy.ts`.

Chart axis labels and window headings are formatted in the household's timezone rather than
the device's, because that is where the server buckets totals.

## Adding a language

1. Add the catalogue as `src/i18n/locales/<code>.json`, translated from English.
2. Register it in `SUPPORTED_LOCALES` and in the resources map in `src/i18n/index.ts`.
3. Add it to the language list in settings and to the storage schema for the preference.
4. Run the tests: the parity checks fail loudly on anything missed.

Store listing copy is separate, under `fastlane/metadata`, and is still English only.

## A caveat worth keeping

The four non-English catalogues were machine translated and have not been reviewed by
native speakers. Energy terminology is exactly where that goes wrong in ways a native
speaker spots instantly. Budget a review pass before a real release.
